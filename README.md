# Homebrew tap for DuoDisplay

[DuoDisplay](https://github.com/LB26121/DuoDisplay) turns one Mac into a low-latency second display for another, connected by a Thunderbolt cable.

```bash
brew install --cask lb26121/duodisplay/duodisplay
```

Install it on both Macs, then follow the [setup](https://github.com/LB26121/DuoDisplay#setup-once).

The cask is updated automatically by DuoDisplay's release workflow. Report problems in the [DuoDisplay repository](https://github.com/LB26121/DuoDisplay/issues).
